# NexVolunteer

NexVolunteer es una aplicación móvil desarrollada en Android Studio utilizando Kotlin y Firebase, enfocada en conectar voluntarios con eventos sociales, educativos, ambientales y tecnológicos. La plataforma permite que usuarios y empresas (partners) participen activamente en iniciativas de impacto social mediante eventos, colaboraciones y actividades comunitarias.

---
